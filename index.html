MaketOgon Drive

A private, single-user tool. Not a public service.

MaketOgon Drive is an internal automation script used by its owner. It builds advertising mockup images (flags, tents, T-shirts with a client's logo) and uploads them to one folder in the owner's own Google Drive, so that the owner's colleagues can open them by a shared link.

The script runs on the owner's computer through rclone and uses the Google Drive API only to create folders and upload, replace or move to trash image files inside that one Drive folder. It is not offered to other users.

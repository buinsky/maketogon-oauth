Privacy policy — MaketOgon Drive

Last updated: 18 November 2026

MaketOgon Drive is a private automation script used by a single person (the owner) on the owner's own computer. It is not a public service and has no other users.

What Google data is accessed

With the owner's consent, the script uses the Google Drive API (through rclone) to list, create, upload, replace and move to trash files and folders inside one folder of the owner's Google Drive, where advertising mockup images are stored. It does not read Gmail, contacts, calendar or any other Google data.

How the data is used and stored

The access token is stored only on the owner's computer, in the rclone configuration file. Files are uploaded to the owner's Google Drive and nowhere else. No Google user data is sold, shared with third parties, used for advertising, or used to train AI models. There is no analytics or tracking.

How to revoke access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue in the GitHub repository of this page.

По-русски

Скрипт одного пользователя работает на его компьютере и через Google Drive API (rclone) создаёт, загружает, заменяет и отправляет в корзину файлы только в одной папке его Google Диска. Токен доступа хранится только на компьютере владельца. Данные Google никому не передаются, не продаются, не используются для рекламы и обучения ИИ. Отозвать доступ — myaccount.google.com/permissions.
